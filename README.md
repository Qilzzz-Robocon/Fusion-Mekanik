A. Hollow maker

Hollow maker ini digunakan ketika proses pembuatan desain robot, lalu butuh untuk meng-estimasi berat dari base robot dan untuk menyiapkan URDF file robot untuk menjalankan simulasi oleh programmer.

Cara install : 

1. Unduh kode di HollowSurfaceAddIn.manifest dan HollowSurfaceAddIn.py
2. buat satu folder dan beri nama HollowSurfaceAddin
3. buka menu add-in di Fusion 360 <img width="1920" height="1200" alt="image" src="https://github.com/user-attachments/assets/1cb14409-d83d-469b-b6eb-0fa2fede30d0" />
4. Tambahkan dengan menekan tombol "+" di menu add-in <img width="1070" height="685" alt="image" src="https://github.com/user-attachments/assets/8e971a47-68cb-4724-a014-b9799770ac50" />
5. Pilih "Script and Add-in from device" <img width="1067" height="684" alt="image" src="https://github.com/user-attachments/assets/cc8f7f86-522a-4ce6-82a6-d68cdc84182b" />
7. Pilih folder sebelumnya yang bernama HollowSurfaceAddin lalu "Open"
8. Pastikan opsi "Run on startup" dan "Run" diaktifkan <img width="1064" height="678" alt="image" src="https://github.com/user-attachments/assets/4536302c-7f93-441d-9e68-289e2ed27bdb" />
9. Close
